# Rival first names, for the whole world.
#
# ---------------------------------------------------------------------------
# WHY THIS IS NOT ONE LIST PER COUNTRY
#
# There are about two hundred countries and maybe thirty name cultures. Egypt,
# Jordan, Morocco and the Gulf draw from one pool; Spain and every country in
# Latin America draw from another. Writing two hundred lists would mean writing
# the same names over and over and maintaining every copy — which is exactly the
# thing you said you did not want to be doing in two weeks.
#
# So: a pool per CULTURE, and a line per COUNTRY saying which pools it draws
# from and in what proportion. Adding a country is one line. Nothing unmapped
# breaks — it falls to [global].
#
# The proportions are the point. A US leaderboard that is all Jacob and Emily
# reads as a list somebody wrote. Mixing is what makes it read as people.
#
# ---------------------------------------------------------------------------
# FORMAT
#
#   [culture:<name>]   starts a pool; every line after it is one name
#   <CC> = <culture>*<weight> ...   a country, under [map]
#
# Every name is 10 characters or fewer, so "Name K" and "Name22" still fit the
# 14-character leaderboard row. Latin only — the font atlas has nothing else.
# Lines starting with # are notes.
# ---------------------------------------------------------------------------
